## Запуск и отладка тестов


**Запус тестов**

запускать тесты можно через командную строку. пример

```bash
pytest
```

по умолчанию все тесты запускаются без открытия браузера а результаты отображаются в терминале


**Запуск через header**

так окно браузера откроется и после завершения тестов закроется

пример кода:

```bash
pytest --headed
```

**Запуск в разных браузерах**

чтобы указать через какой именно браузер запускать тест вы можете использовать —-browser название браузера так же можете указывать несколько браузеров 

пример кода

```bash
pytest --browser webkit --browser firefox
```


**Запуск опрпеделенных тестов**

чтобы запустить 1 или несколько тестовых файлов просто укажите его название


пример кода:

```bash
pytest tests/test_todo_page.py tests/test_landing_page.py
```

чтобы запустить определенный тест просто укажите его название

фирменный пример кода:

```bash
pytest -k test_add_a_todo_item
```


**Запуск тестов параллельно**

чтобы запустить тесты параллельно используйте флаг —-numprocesses а затем укажите количество процессов в которых вы хотите запустить тесты рекомендация половина логических ядер процессора

пример кода:

```bash
pytest --numprocesses 2
```

(при условии что pytest-xdist установлен)

**Отладка тестов**

Поскольку Playwright написан на Python, вы можете отлаживать его с помощью любого отладчика, например с помощью расширения Python в Visual Studio Code. Playwright поставляется с Playwright Inspector, который позволяет пошагово выполнять вызовы API Playwright, просматривать журналы отладки и изучать локаторы.

чтобы отладить все тесты надо выполнить следующие команды 

powershell:

```powershell
\$env:PWDEBUG=1
pytest -s
```

bash:

```bash
PWDEBUG=1 pytest -s
```

batch:

```cmd
set PWDEBUG=1
pytest -s
```
