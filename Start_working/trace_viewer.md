**Playwright Trace Viewer - это инструмент с графическим интерфейсом, который позволяет вам просматривать записb Playwright trace ваших тестов. переходить назад и вперед по каждому действию вашего теста и визуально видеть, что происходило во время каждого действия.**

---

### **Запись трасировки**

Трассировку можно записать, запустив тесты с флагом `--tracing`

пример кода:
```bash
pytest --tracing on
```

Варианты трассировки:
* **1. on:** Записывать трассировку для каждого теста
* **2. off:** Не записывать трассировку. (по умолчанию)
* **3. retain-on-failure:** Записывать трассировку для каждого теста, но удалять все трассировки из успешных запусков тестов.

Трассировка будет записана и помещена в файл с именем `trace.zip` в вашем рабочей папке.

---

### **Открытие трассировки**

вы можете открыть сохраненную трассировку через командную строку или через сайт по данной ссылке: https://playwright.dev

После открытия вы можете нажимать на каждое действие или использовать временную шкалу, чтобы видеть состояние страницы до и после каждого действия. Вы также можете просматривать журнал, исходный код и сетевые данные на каждом этапе тестирования.

пример кода:
```bash
playwright show-trace trace.zip
```
